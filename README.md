AI Business Assistant для малого бизнеса (Тараз, Казахстан)
Интеллектуальный MVP-сервис для автоматизации клиентского сервиса, обработки заказов и поддержки местных предпринимателей в Таразе и Жамбылской области. Проект разработан для хакатон-трека AI for SME & Local Business.

О проекте
Малый и средний бизнес в регионах часто сталкивается с потерей клиентов из-за задержек с ответами в мессенджерах и рутинных вопросов по ценам. Наше решение объединяет Telegram-бот с надежным бэкендом на Django REST Framework и базой данных PostgreSQL, обеспечивая круглосуточную автоконсультацию клиентов на основе актуального каталога товаров и цен в тенге.

Технологический стек
Бэкенд: Python, Django, Django REST Framework (DRF)

База данных: PostgreSQL, Redis

Контейнеризация: Docker & Docker Compose

Клиент: Telegram Bot (aiogram асинхронный фреймворк)

Инструкция по запуску проекта
Для запуска проекта на вашем компьютере должен быть установлен Docker и Docker Compose.

Шаг 1. Клонирование и запуск бэкенда
Откройте терминал в папке с проектом и запустите контейнеры одной командой:
docker-compose up --build
Эта команда автоматически развернет базу данных PostgreSQL, Redis и запустит Django-сервер.

Шаг 2. Применение миграций и создание суперпользователя
В новом окне терминала выполните команды для настройки базы данных:
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py createsuperuser
(Следуйте инструкциям на экране, чтобы задать логин и пароль для панели администратора).

Шаг 3. Запуск Telegram-бота
Откройте файл bot.py и вставьте ваш токен Telegram-бота, полученный у @BotFather.

Установите зависимости бота и запустите его:
pip install aiogram aiohttp
python bot.py

Панель управления и администрирование
Владелец бизнеса или администратор платформы может управлять товарами, ценами, остатками и просматривать историю диалогов через стандартную админ-панель Django:

Админка: http://localhost:8000/admin/

API эндпоинт бизнесов: http://localhost:8000/api/businesses/
